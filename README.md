# Prueba Claude + GitHub

Programa de ejemplo para probar el flujo de trabajo con Claude Code y GitHub.

## Contenido

- `calculadora.py`: una calculadora sencilla por línea de comandos (suma, resta, multiplicación, división).
- `test_calculadora.py`: pruebas con `pytest`.

## Uso

Ejecutar la calculadora:

```bash
python calculadora.py
```

Ejecutar las pruebas:

```bash
pytest
```
